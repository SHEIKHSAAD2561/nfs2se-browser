NFS II SE in the browser

Bring your own game files. Nothing is uploaded; everything runs locally in your browser.

  1. Load your game files

    Pick the installed DOS game folder, or a .zip of it.

    …or drop a .zip here

  2. Game CD image (optional)

    If the game asks for the CD, add the disc as .iso or .cue + .bin. It's mounted as drive D:.

  3. Launch settings

    Edit dosbox.conf by hand

    Changes to the dropdowns above regenerate this text.
